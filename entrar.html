ACESSO FAMILIAR

ENTRAR

Acede à base de dados da família através do teu endereço de e-mail.

Entrar com palavra-passe

Usa o teu e-mail e a palavra-passe atribuída pelo Nuno.

Para criar um acesso ou recuperar a palavra-passe, fala com o Nuno. Cada pessoa tem uma conta individual.

Entrar por ligação de e-mail

Alternativa para uma conta já preparada. O envio está sujeito aos limites do serviço de e-mail.

Confirmar código

Se o email tiver um código de seis dígitos em vez de uma ligação, introduz esse código.

Acesso confirmado

ABRIR O SITE

As páginas de dados exigem sessão. Confirma sempre o estado da gravação no Supabase antes de sair.

Gerir acessos

Só o Nuno pode criar contas, atribuir palavras-passe e suspender acessos.

Usa uma palavra-passe diferente para cada pessoa, com pelo menos 12 caracteres. Partilha-a pessoalmente ou por um canal privado.

As palavras-passe não são apresentadas na lista. O acesso aos dados continua sujeito à migração do site.
